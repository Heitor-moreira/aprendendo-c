# Aprendendo C

Repositório com exercícios de programação em C, desenvolvidos durante a disciplina Introdução a computaçãoo no UNISAL.

Veja a lista completa de exercícios em [Lista de Exercícios 1](docs/Introd_Comput_lista_1.pdf).

## Exercícios
- 01 - Multiplica dois números inteiros
- 02 - Calcula área de um retângulo
- 03 - Calcula a area do terreno usando variavel X
- 04 - Calcula a quantidade necessária de fotos para cobrir uma parede
- 05 - Calcula a area da frente de um terreno com base na quantidade de terrenos inserida
